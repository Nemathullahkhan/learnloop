# Examples

Everything here is meant to be copied and reused.

| Folder | What it is | Use it for |
|---|---|---|
| [templates/](templates/) | Blank documents the roles produce or read | Start a topic: fill the brief, then the map, then keep the logs |
| [practice-app/](practice-app/) | Single-file flashcard app with spaced review | The Retain stage: drill the cards the clerk writes |
| [rate-limiting/](rate-limiting/) | A full worked example: learn HTTP rate limiting, then build it | Seeing every role used once, from first question to running code |

## Templates

| File | Written by role | Read by role |
|---|---|---|
| [learning-brief.md](templates/learning-brief.md) | interviewer | mapmaker |
| [learning-map.md](templates/learning-map.md) | mapmaker | you, every session |
| [session-log.md](templates/session-log.md) | you (one line per role) | `/learn auto`, diagnostician |
| [mistake-log.md](templates/mistake-log.md) | examiner, checker, listener, sparring partner | diagnostician, clerk |
| [rubric.md](templates/rubric.md) | you, or AI draft | checker, examiner |
| [flashcards.csv](templates/flashcards.csv) | clerk | practice app, Anki |

The worked example in [rate-limiting/](rate-limiting/) is written by hand to show the shape of each role's output. It is not a recorded AI session.
