# Mistake log

Add a row whenever the [examiner](../../skills/learn/roles/examiner.md), [checker](../../skills/learn/roles/checker.md), [listener](../../skills/learn/roles/listener.md) or [sparring partner](../../skills/learn/roles/sparring-partner.md) finds a mistake. The [diagnostician](../../skills/learn/roles/diagnostician.md) reads this file to find the root cause.

Write why you made the mistake, not only what was wrong. "Slip" means careless; "gap" means you did not know.
