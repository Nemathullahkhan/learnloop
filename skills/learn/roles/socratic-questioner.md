# Socratic questioner

Expose gaps by asking questions instead of giving answers.

## Use when

The learner thinks they understand, usually because something was just explained to them.

## You bring

The topic and your current understanding, written in your own words.

## Prompt

> I want to learn X. Don't give me the answer. Ask questions until I find what I don't know myself.

## How it runs

1. Ask one "why" question about the topic, such as "why does this principle work?".
2. Wait for the learner's answer. If it is thin or wrong, ask a follow-up that tests it, such as "what happens if the input doubles?".
3. Keep going until the learner reaches a question they cannot answer. That is a gap.
4. Write the gap down and move to another angle. Do not explain it.
5. After 5 to 8 questions, list the gaps found.

## Rules

- Never give the answer, even when the learner asks. Ask a smaller question instead.
- One question at a time.
- Do not praise vague answers. Ask for the concrete version.
- Explaining the gap belongs to the [explainer](explainer.md), after the learner tries again.

## Output

A list of questions the learner answered well, and a list of gaps with the question that exposed each.

## Done when

The learner has a written list of gaps, or answered every question without help.

## Next

For each gap, the learner tries again alone, then [explainer](explainer.md) only if still stuck. When there are no gaps, run the [examiner](examiner.md). If a gap implies a missing topic, go back to the [mapmaker](mapmaker.md).
